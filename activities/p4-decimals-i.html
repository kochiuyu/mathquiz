Teacher key

1. 3/10 = 0.3, read “zero point three”; 27/100 = 0.27, read “zero point two seven”. Mark 3 of 10 strips and 27 of 100 cells. Both whole squares have equal area; one tenth-strip has ten times the area of one hundredth-cell. A hundredth-cell is not a ten-thousandth of the original whole without further explicit subdivision.

2. 3.4021: ones 3; fractional digits 4,0,2,1 have values 0.4,0,0.002,0.0001. Integer part 3; fractional part 0.4021 (digits 4021). Read “three point four zero two one”. 0.0705: ones 0; fractional digits 0,7,0,5 have values 0,0.07,0,0.0005. Integer part 0; fractional part 0.0705 (digits 0705). Read “zero point zero seven zero five”. Both show four decimal places. A filled chart does not prove actual oral reading.

3. 0.5 = 0.50 = 0.5000, showing one, two and four decimal places. The same half is 5 tenths, 50 hundredths or 5000 ten-thousandths. Written place count does not change value or imply measurement precision. 4.07 < 4.7 because hundredths differ from tenths; 4.070 = 4.07. Explain this specific interior-zero example, not an unsupported universal claim about every zero deletion.

4. 0.25 = 1/4 < 0.49 < 1/2 = 0.50 < 1. Compare via 25/100 and 50/100; the supplied fraction denominators divide 100. 12.35 > 12.205 (tenths 3 > 2); 0.0999 < 0.1 (tenths 0 < 1). More digits need not mean greater value.

5. HK$23 and 50 cents = HK$23.5; HK$23.50 is equal in value. 50 cents is 50/100 of a dollar. 1.25 m = 125 cm: 1 m represents 100 cm and 0.25 m represents 25 cm. 1.234 L = 1234 mL: 1 L represents 1000 mL and 0.234 L represents 234 mL. Keep units; supplied values are not observed measurements. No decimal addition algorithm is required.

6. Accept justified pupil-created examples such as 2.3 = 2.30 without prefilling evidence. Correct the supplied claim to 4.07 < 4.7 with hundredths/tenths reasoning. Example 0.0007 reads “zero point zero zero zero seven”; digit 7 has value 0.0007. Many examples are valid. Removing terminal zeros from the fractional part is not permission to delete zeros from the whole-number part.

教師解答

1. 3/10 = 0.3，讀作「零點三」；27/100 = 0.27，讀作「零點二七」。分別標出10條中的3條及100格中的27格。兩個整體面積相同，一條十分之一是一格百分之一的十倍。未明確細分前，一格百分之一不是原整體的萬分之一。

2. 3.4021：個位3；小數位數字4、0、2、1的值為0.4、0、0.002、0.0001。整數部分3，小數部分0.4021（點後數字4021），讀作「三點四零二一」。0.0705：個位0；小數位數字0、7、0、5的值為0、0.07、0、0.0005。整數部分0，小數部分0.0705（點後數字0705），讀作「零點零七零五」。兩數均寫四個小數位。填好表不證明已實際讀出。

3. 0.5 = 0.50 = 0.5000，分別寫一、二、四個小數位。同一半為十分之五、百分之五十或萬分之五千。所寫位數不改變數值，也不表示量度精確度。4.07 < 4.7，百分位不同於十分位；4.070 = 4.07。解釋指定中間零的例子，不概括成刪去任何零必然改值。

4. 0.25 = 1/4 < 0.49 < 1/2 = 0.50 < 1，可用25/100及50/100比較，所給分母是100的因數。12.35 > 12.205（十分位3 > 2）；0.0999 < 0.1（十分位0 < 1）。數字較多未必數值較大。

5. 港幣23元50仙 = 港幣23.5元，23.50元亦等值。50仙是1元的50/100。1.25米 = 125厘米：1米代表100厘米，0.25米代表25厘米。1.234升 = 1234毫升：1升代表1000毫升，0.234升代表234毫升。保持單位，提供數值不是實測證據，不要求小數加法直式。

6. 接受學生自創且有理由的例子，如2.3 = 2.30，不預填證據。指定錯誤改成4.07 < 4.7，解釋百分位及十分位。例子0.0007讀作「零點零零零七」，7的值為0.0007；其他正確例子亦可。小數部分末尾可去零不表示可刪去整數部分的零。
