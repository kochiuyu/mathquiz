1. Add and explain a carry.

Write vertically with matching place values aligned. Calculate both. Choose one carry and show why it is needed using place-value counters, a sketch or words.

248 + 176 = ________
126 + 237 + 148 = ________

2. Find a helpful pair.

198 + 37 + 2 = ________

Find a quick way. Show which two numbers you add first and why. Then check by adding in the original order. Do the results agree?

Try 49 + 126 + 51 in your own way. Explain your grouping. You do not need a special name for the rule.

3. Subtract and explain an exchange.

52 − 27 = ________   80 − 46 = ________

Use a place-value drawing or bundles to show what you exchange before subtracting. Do you still have the same starting quantity after the exchange?

82 − 37 − 18 = ________

Show the first result, then subtract the last number. Explain why you worked from left to right.

Check subtraction and solve stories

4. Does changing the grouping work for subtraction?

Use 12 counters. First remove 5, then remove 3. How many remain? Record both steps. ________

Start again with 12. A pupil first finds 5 − 3, then removes only that many from 12. Show what remains. Is this the same action and result as before? Explain using the counters. ________

Which method matches “12, take away 5, then take away 3”? ________

5. Write a calculation and an explanation statement.

a. A school receives 125 notebooks, then 236, then 147. How many notebooks does it receive altogether?

b. There are 72 stickers. 28 are given away, then another 19. How many remain?

c. One class has 63 books and another has 38. How many more books does the first class have?

Estimate, calculate and judge

Teacher: use this part after the pupil can add with carrying and subtract with borrowing.

6. Make a sensible estimate first.

For each calculation, write a rough answer before finding the exact answer. Explain what easy nearby numbers or known facts you used. You do not need a formal rounding rule.

Teacher worked key and feedback

Materials: pencils, extra paper, 12 large counters, place-value counters or bundles of ten and loose ones. Read story text if needed, but do not select the operation for the pupil. Statements may be spoken and transcribed, with support recorded. Keep answers hidden during attempts.

1. 做加法，解釋一次進位。

用直式把相同數位對齊，完成兩題。選一次進位，用數位圓片、圖畫或說話解釋原因。

248 + 176 = ________
126 + 237 + 148 = ________

2. 找方便先加的數對。

198 + 37 + 2 = ________

想一個方便的方法，展示先加哪兩個數及原因。再按原來次序相加核對，結果相同嗎？

用自己的方法試算49＋126＋51，解釋怎樣組合。不用說出規則的專門名稱。

3. 做減法，解釋一次退位。

52 − 27 = ________   80 − 46 = ________

減之前，用數位圖或小棒束展示怎樣交換。交換後，原來的總數有沒有改變？

82 − 37 − 18 = ________

先寫第一次相減結果，再減最後一個數。說明你由左至右計算的次序。

檢查減法及解文字題

4. 減法可以隨意改變先算的部分嗎？

用12個圓片，先拿走5個，再拿走3個。剩多少？記錄兩步。 ________

重新拿12個圓片。有位學生先算5－3，再從12中只拿走這麼多。展示剩下多少。這與剛才的動作和結果相同嗎？用圓片解釋。 ________

哪個方法符合「12個，拿走5個，再拿走3個」？ ________

5. 寫算式，並用語句解釋。

a. 學校先收到125本筆記簿，再收到236本，之後又收到147本。一共收到多少本？

b. 原有72張貼紙，送出28張，再送出19張。還剩多少張？

c. 一班有63本書，另一班有38本。第一班比另一班多多少本？

先估計、再計算、作判斷

教師：學生能做進位加法及退位減法後，才進行本部分。

6. 先作合理估計。

每題先寫大約答案，再求準確答案。解釋用了哪些接近而方便的數，或已知的數量關係。不用正式進捨規則。

估計可以怎樣幫你檢查計算？ ________

教師解答及回饋

材料：筆、白紙、12個大圓片、數位圓片或十支一束的小棒及散支。可按需要讀題，但不要替學生選運算。可讓學生口述語句並代寫，記錄支援。作答時隱藏答案。

題目解答／回饋
1248＋176＝424：8＋6＝14個一，把十個一換成一個十；十位4＋7＋1＝12個十，再換成一個百；百位2＋1＋1＝4。126＋237＋148＝511：個位共21，進2個十，餘1個一；十位2＋3＋4＋2＝11，進1個百，餘1個十；百位1＋2＋1＋1＝5。若漏進位，請學生用小棒核對每欄總數。
2198＋2＝200，再加37＝237。原序198＋37＝235，再加2＝237。49＋51＝100，再加126＝226。接受其他正確方便方法及解釋。若改變加數本身而非次序／組合，請學生核對原來三個數量。不要求背規則名稱。
352換成4個十和12個一：12－7＝5，4－2＝2，結果25。80換成7個十和10個一：10－6＝4，7－4＝3，結果34。交換不改變原數。82－37＝45，再算45－18＝27。若個位倒轉相減，請重建原數並退一個十，不可只用大數字減小數字。
4第一做法12－5＝7，再算7－3＝4。另一做法5－3＝2，再算12－2＝10。4與10不同；先拿5再拿3，不是只拿2。第一做法符合指令。用實物顯示減法不能隨意改先算部分，不要求括號記法或規則名稱。
5a 125＋236＋147＝508。例句：「三次都是收到的，所以相加；學校共收到508本。」b 72－28＝44，再減19＝25。例句：「從原數減去每次送出的，還剩25張。」c 63－38＝25。例句：「較多的書數減較少的，求相差；第一班多25本。」接受意思正確的解釋，不只抄答案句。沒有把比較關係與求總數混合。
6可接受估法：287接近300、196接近200，約500；81接近80、39接近40，約40。準確答案483及42。接受其他先作、有依據的估計。883不合理：兩個加數分別比300和200小，總和應比500小。不要求不等號或固定誤差百分比。先算準確答案才估，只記作核對，不當作事前估計。
