P1 · Length and distance (I)

Teacher-led practical activity · Name Date

Materials: two paper strips of different lengths, two floor markers, a piece of string, and identical paperclips or blocks.

  1. Compare lengths: Put both strips against the same starting line. Circle the longer strip: A / B. Tell the teacher what you aligned.
  2. Compare distances: Mark one Start point and two endpoints A and B. Stretch string straight from Start to each endpoint. Circle the farther point: A / B. Compare the straight distances, not a walking route.
  3. Choose one improvised unit: Use identical paperclips or identical blocks for both comparisons. Place them end to end with no gaps or overlaps. Record the counts below.

小一 · 長度和距離（一）

教師帶領的實作活動 · 姓名 日期

材料：兩條不同長度的紙帶、兩個地面標記、一段繩子，以及大小相同的回形針或方塊。

  1. 比較長度：把兩條紙帶的起點對齊。圈出較長的紙帶：A / B。向老師說出對齊了甚麼。
  2. 比較距離：標示同一個起點，以及終點A和B。把繩子由起點沿直線拉到每個終點。圈出較遠的點：A / B。比較直線距離，不比較行走路線。
  3. 選用自訂單位：兩次比較都用大小相同的回形針或方塊。首尾相接地排放，不留空隙，也不重疊。在下表記錄數目。
