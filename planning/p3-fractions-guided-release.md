## Scope

The [EDB notes, PDF pages 54–55 / printed 48–49](https://www.edb.gov.hk/attachment/en/curriculum-development/kla/ma/curr/EN_KS1_e.pdf#page=54) were read again. This release addresses fraction concepts and equivalence (3N5.1–2), with equal quantities, object and set wholes, vocabulary, zero and one, and diagram/physical explanations. The same-sized strips support equivalence without a symbolic expansion/reduction procedure. **3N5.3–4 remain unfinished guided work**; this is not whole-unit completion. Existing [activity sheets](../activities/p3-fractions-i.html) are linked; tasks 1–3 supply practical support, while their later tasks are beyond this foundation release.

## Marking and persistence

Object/set entry questions explicitly request **pictured counts**, so a three-out-of-twelve diagram asks for numerator 3 and denominator 12. A response of 1/4 is acknowledged as the same amount while explaining that this task asks for pictured counts; it is not labelled a different fraction. Equivalence itself is assessed by same-whole diagrams. No simplest form is required. The inherited question bank and its count-specific scorer remain untouched.

Fraction records use a new topic namespace in the existing per-learner store. First responses, one supported retry, observation notes and original inquiry predictions remain separate. Model actions are temporary and unscored. Earlier topics, learner records, practice-bank IDs/payloads and score rules are preserved. Damaged/future/oversized records stay protected; stale tabs cannot overwrite saved work; blocked storage is explicitly temporary.
