# P3 TSA 2026: question variety

Implemented on 19 November 2026 (Hong Kong). These are original practice tasks informed by the eight user-supplied papers, not reproductions of official questions or an official mock assessment. The supplied English and Chinese forms are paired references, not eight independent curricula.

## Release scope

The P3 bank grows from **35 to 50 MathQuiz practice types**, with **1,800 levelled tasks**. The 15 additions are HKEAA TSA-informed adaptations and labelled MathQuiz extensions, not new EDB learning units or official competency counts. [Source classification and verified BC references](p3-source-classification.md). The addition is **15 skills × 12 contexts × 3 levels = 540 tasks**. Easy, Normal and Difficult share the twelve contexts: Easy supplies a relevant cue; Normal removes the cue; Difficult adds a check within the skill. The existing 420 frozen contexts / 1,260 levelled tasks retain their exact payloads and IDs.

Entry: [new TSA skills](https://kochiuyu.github.io/mathquiz/skill-levels.html?p=3&q=TSA). Each new skill has fixed-level practice, four short sets, all-twelve practice, pupil paper, worked key, language transfer and Smart practice. These additions are in the skills system; the separate mixed-quiz builder retains its existing families.

## Implementation and response rules

- `p3-tsa.js` adds tasks to the bank after the original data loads. CommonJS and browser entry points use the same extension. It does not mutate the frozen seed catalogue.
- All numerical responses use the existing P3 non-negative numeral contract, including full-width numerals. No new shared marking rule is introduced.
- Equivalent-fraction tasks ask Yes/No for **every** displayed card, which represents a select-all demand with explicit per-card feedback. Angle ordering uses a choice for each position. These use existing accessible form controls and per-field credit.
- Money questions explicitly label cents/仙. They do not interchange 40 cents with 40角. Prices and change use integer cents; one角 is ten仙.
- Calendars are generated from real UTC dates in 2027; weekday placement and inclusive duration are independently checked.
- SVG dial ticks, balance pans, angles, road maps and shapes remain sharp in print. Scale reading uses a displayed scale and never asks pupils to measure screen pixels with a physical ruler.
- Calendar headings use short weekday labels to fit narrow screens. Text, table headings, SVG descriptions, prompts and worked explanations are bilingual.
- Chart completion online asks for the missing bar value or picture count and a title choice. Pupils can draw into the incomplete chart on the printed paper. Online freehand drawing, arbitrary chart titles and handwriting/working assessment are outside this release.
- New skills are discoverable from the P3/all-years resource library and the levelled directory. Every new fixed-level page links to its Smart practice route. Return links for 3R1 lead to the skill directory.

## Validation

Run `node tests/p3-tsa-static.cjs` for independent answer oracles across all 540 additions, all 45 bilingual levels, stable IDs, field contracts, exact directory mapping and a SHA-256 check preserving every original P3 task. Run `node tests/p3-skill-static.cjs` for the unchanged original 35 skills. That test explicitly retains its original scope; the new assertions live in the TSA test.

Run [the focused browser checks](https://kochiuyu.github.io/mathquiz/tests/p3-skill-levels.html?scope=tsa) for all 15 × 3 × 2 skill/level/language combinations in quiz, paper and key views; 30 Smart practice sessions through all three levels; narrow-screen layouts; partial credit; language transfer and directory routes. Existing all-P3 checks remain available without `scope=tsa`.

Local static checks pass, including shared Smart practice across all 285 skills / 10,260 canonical answers and exact directory mappings for all six banks. Local browser serving is blocked by this execution environment, so browser verification used the published site.

The initial full live run passed **133/133 cases**. The short-set refinement then passed **all 36 affected cases again**, including both languages and every changed geometry, route and chart type. These reruns overlap the original run: **133 distinct live cases are verified**, not 169. Both runtime deployments succeeded. [Release evidence](p3-tsa-evidence.json) records scope, commits and limitations. Physical printing and classroom calibration are not claimed.

Every short chart set now mixes bar/pictogram formats and missing categories. Every short route set includes either route being shortest and a tie; boundary sizes and solid orientations also vary. These are enforced by the static variety checks.

## Source clarification — 19 November 2026

Both supplied HKEAA assessment-design documents have now been read, including their item/BC tables. The directory, new practice cards, question pages, papers, worked keys and Smart practice distinguish the EDB curriculum framework, HKEAA assessment references and original MathQuiz extensions. P3 TSA covers P1–P3; the Easy/Normal/Difficult levels and extra checks are MathQuiz teaching choices. Variant labels flag non-1:1 pictograms, bar-chart intervals outside 1/2/5, symbolic equivalence and combined capacity tasks. Related BC codes are reference mappings, not official endorsement. Question operands, answers, IDs, marks and progression are unchanged.
