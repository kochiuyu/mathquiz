# Hong Kong primary mathematics quiz plan

Teachers choose a year, unit and skill, preview the exact questions, replace individual items, then download a pupil paper and a worked key or distribute an online quiz. Pupils can also practise a single skill without an account.

## Curriculum map

Each code opens the EDB page containing the official objectives and teaching notes. The third column proposes one quiz task per unit. Authors should check the linked objective, permitted operations, number ranges and exclusions before releasing a template. Teachers can mix units in their own teaching order. The 2017 curriculum supplement is the baseline. #### Live P1 authoring and marking notes

Code check: **15 November 2026**. The purpose labels describe the decision each item asks a pupil to make. The misconceptions are **hypotheses to probe**, not observed pupil errors; the small teacher-reported trials did not include item-level responses. The [objective and scope map above](#live-p1-family-to-objective-map) supplies EDB sources and parameter bounds for the same seven live families.

**Shared online rule.** Every P1 generated item is worth one mark. A blank field stops submission and asks the pupil to complete that question. For the five numeric families (`add1`, `next1`, `count20a`, `parts18a`, `storyadd1`), new `v=3` pupil links require digits forming the stored whole number. Full-width digits and outer spaces are normalised; fractions, decimals, signs, units and words are rejected. Thus `１１` scores for 11 but `22/2` and `11.0` do not. Previously shared `v=2` links retain their original value-based marking, including equivalent fractions and decimals; fixed `v=1` quizzes are unchanged. P4/P6 numeric marking is also unchanged in either custom-link version. The builder retains the version of an opened `v=2` link when it generates pupil, paper, key and language links; the home page starts new `v=3` links. Printed numeric answers require teacher marking; the site does not score paper.

| Family | Assessment purpose | One-mark answer rule | Misconception to probe (hypothesis) |
|---|---|---|---|
| `add1` | **Apply:** combine the red and blue bead quantities in a short joining story. | Numeric rule above; the value must equal the sum of the two stated groups. | Give only the second group's count rather than the total. |
| `next1` | **Identify:** continue a consecutive sequence by one. | Numeric rule above; enter the next value in the sequence's inline blank. | Repeat the last shown number instead of moving on one. |
| `count20a` | **Identify:** find the cardinal quantity of a pictured collection. | Numeric rule above; the value must equal the number of drawn counters. | Count a counter twice when moving to a new row. |
| `parts18a` | **Calculate:** recover an unknown one-digit part from the whole and known part. | Numeric rule above; the value must equal `whole − known part`. | Enter the known part or whole instead of the missing part. |
| `pictureadd1` | **Represent:** translate two pictured groups into a horizontal addition sentence. | Online: after full-width normalisation and removal of whitespace, accept only `a+b=total` or `b+a=total` using the pictured one-digit addends and correct total. Another pair with the same total is wrong. The online total is compared numerically, so `08` is accepted for 8. On paper, accept either pictured addend order. | Write an equation with the correct total but addends that do not match the picture. |
| `storyadd1` | **Apply:** find the combined quantity after a group is added. | Numeric rule above; the value must equal the starting group plus the added group. The response does not have to show working. | Report only the newly added group. |
| `otherway1` | **Represent:** construct a different two-part composition of the same whole. | Online: two fields must each contain a positive one-digit whole number; their sum must equal the shown total, and their unordered pair must differ from the pictured pair. Either order of a new pair is accepted. On paper, a readable labelled drawing or horizontal equation meeting the same conditions earns one mark; see the [full rubric](p1-exit-ticket.md#marking-the-two-open-response-items). | Reverse the pictured pair and call it a different composition. |

**Response-policy decision.** New `v=3` P1 numeric items use the whole-number response specified in the [exit-ticket brief](p1-exit-ticket.md#ordered-item-briefs). `v=2` keeps its published scoring rule so an old pupil link still marks as it did when shared. Both versions retain the same question IDs, values, paper and worked key; the version selects the online response policy. The purpose labels and misconception hypotheses should be revisited with item-level classroom evidence.

#### Live P4 authoring and marking notes

Code check: **15 November 2026**. These notes cover the two generated P4 families; the fixed v1 P4 quiz is separate. The [objective and scope map above](#live-p4-family-to-objective-map) supplies the EDB sources and parameter bounds. **Shared online rule.** Each generated P4 item is worth one mark. A blank perimeter field or a factor item with no checkbox selected stops submission and asks the pupil to complete it. The paper is for teacher marking. `v=2` and `v=3` links use the same P4 answer rules.

| Family | Assessment purpose | One-mark answer rule | Misconception to probe (hypothesis) |
|---|---|---|---|
| `per1` | **Calculate:** use the stated length and width to find the boundary length of a rectangle. | The submitted value must equal `2 × (length + width)`. The unit `cm` is already shown beside the field. The marker normalises full-width characters, trims outer spaces and accepts a signed numeral, decimal or fraction with the correct value. For the 12 cm by 5 cm item, `34`, `34.0` and `68/2` score; `34 cm` and `60` do not. | Multiply length by width, finding the area instead of the perimeter; for 12 cm by 5 cm, enter 60 instead of 34. |
| `factor1` | **Identify:** decide which of four listed numbers divide the target exactly. | Select **all and only** the listed factors. The two correct selections together earn one mark; one missing factor or an extra non-factor earns zero, with no partial credit. For 16 and choices 2, 3, 4, 5, select exactly 2 and 4. On paper, use the same all-and-only-listed-factors rule. | Treat a small candidate as a factor without checking exact divisibility; for example, select 3 as a factor of 16. |

The online result does not by itself establish why a pupil chose an answer. Discuss an error with a teacher or collect anonymised item-level responses before treating either hypothesis as an observed misconception.

## Three prototype quizzes

The following are original English and Traditional Chinese item briefs. Use the pupil's selected language throughout each output. Keep each diagram beside its question in both formats.

| Unit | English prompt | 繁體中文題目 | Worked answer or display requirement |
|---|---|---|---|
| 1N1 | How many stars are there? | 圖中有多少顆星星？ | Show five stars in one row and two beneath. Circle or tap 6, 7 or 8. Five and two make **7**. |
| 1N2 | Wai has 4 pencils. Mum gives Wai 3 more. How many pencils does Wai have now? | 小慧有4枝鉛筆，媽媽再給她3枝。小慧現在有多少枝鉛筆？ | 4 + 3 = **7**. Provide large numeral choices. |
| 1S2 | Which shape is a triangle? | 哪個圖形是三角形？ | Draw a square, a rotated triangle and a circle. Choose the second shape. It has three straight sides. |
| 4N3 | Circle every factor of 36 in this list. | 圈出以下所有36的因數。 | Options 4, 6, 8, 12. Accept exactly **4, 6, 12** in any order. Each divides 36 with no remainder. |
| 4M1 | A rectangular noticeboard is 90 cm long and 60 cm wide. How much tape goes around it once? | 一塊長方形壁報板長90厘米、闊60厘米。沿四邊貼一圈需要多少厘米膠帶？ | Label adjacent sides. 90 + 60 + 90 + 60 = **300 cm**. Supply the unit beside the answer box. |
| 4D1 | How many more books did Class A borrow than Class C? | A班比C班多借了多少本書？ | Draw bars A = 25, B = 20, C = 15 with a zero baseline and ticks every 5 books. 25 − 15 = **10 books**. |
| 6N4 (live v1 label: 6N3) | A club has 40 members. Sixteen cycle to school. What percentage cycle to school? | 一個學會有40名會員，其中16人踏單車上學。踏單車上學的會員佔百分之幾？ | 16 ÷ 40 × 100% = **40%**. Supply % beside the field. |
| 6M4 | A ferry travels 18 km in 45 minutes. Find its average speed in km/h. | 一艘渡輪在45分鐘內航行了18公里。它的平均速率是多少公里每小時？ | Ask for hours and speed in separate boxes. 45 ÷ 60 = **0.75 h**. 18 ÷ 0.75 = **24 km/h**. Accept 3/4 as well as 0.75. |
| 6D1 | A pupil read 12, 18 and 15 pages over three days. How many pages per day on average? | 一名學生在三天內分別閱讀了12、18和15頁。平均每天閱讀多少頁？ | (12 + 18 + 15) ÷ 3 = **15 pages**. Include working space. |

## From plan to release

1. Build the nine fixed examples first. Store each quiz as an ordered set of versioned questions containing language, values, diagrams, answer rules, marks and worked steps. Reopening a quiz must reproduce it exactly.
2. Generate a separate downloadable A4 question paper and answer key from the same record. Check Chinese glyphs, grayscale diagrams, space for working and page breaks. Give P1 pupils large targets online. Offer keyboard input and labelled controls for selection and numeric answers.
3. Add a teacher preview with single-item replacement, then shareable links. Practise mode gives feedback after each item. An assigned quiz shows solutions after submission. The first release assumes account-free self-marking. Explanations and open-ended investigations require a rubric or teacher review.
4. Turn reviewed examples into generators. Test boundary values, equivalent answers, unique choices, unit conventions and agreement between each diagram and solution. Only enable a skill in the builder once it has a reviewed bilingual template and passes print and mobile checks.
