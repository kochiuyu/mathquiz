#### Live P1 authoring and marking notes

Code check: **15 November 2026**. The purpose labels describe the decision each item asks a pupil to make. The misconceptions are **hypotheses to probe**, not observed pupil errors; the small teacher-reported trials did not include item-level responses. The [objective and scope map above](#live-p1-family-to-objective-map) supplies EDB sources and parameter bounds for the same eight live families.

**Shared online rule.** Every P1 generated item is worth one mark. A blank response stops submission and asks the pupil to complete that question. For the five numeric families (`add1`, `next1`, `count20a`, `parts18a`, `storyadd1`), new `v=3` pupil links require digits forming the stored whole number. Full-width digits and outer spaces are normalised; fractions, decimals, signs, units and words are rejected. Thus `１１` scores for 11 but `22/2` and `11.0` do not. Previously shared `v=2` links retain their original value-based marking, including equivalent fractions and decimals; fixed `v=1` quizzes are unchanged. P4/P6 numeric marking is also unchanged in either custom-link version. The builder retains the version of an opened `v=2` link when it generates pupil, paper, key and language links; the home page starts new `v=3` links. Printed numeric answers require teacher marking; the site does not score paper.

| Family | Assessment purpose | One-mark answer rule | Misconception to probe (hypothesis) |
|---|---|---|---|
| `add1` | **Apply:** combine the red and blue bead quantities in a short joining story. | Numeric rule above; the value must equal the sum of the two stated groups. | Give only the second group's count rather than the total. |
| `next1` | **Identify:** continue a consecutive sequence by one. | Numeric rule above; enter the next value in the sequence's inline blank. | Repeat the last shown number instead of moving on one. |
| `count20a` | **Identify:** find the cardinal quantity of a pictured collection. | Numeric rule above; the value must equal the number of drawn counters. | Count a counter twice when moving to a new row. |
| `parts18a` | **Calculate:** recover an unknown one-digit part from the whole and known part. | Numeric rule above; the value must equal `whole − known part`. | Enter the known part or whole instead of the missing part. |
| `pictureadd1` | **Represent:** translate two pictured groups into a horizontal addition sentence. | Online: after full-width normalisation and removal of whitespace, accept only `a+b=total` or `b+a=total` using the pictured one-digit addends and correct total. Another pair with the same total is wrong. The online total is compared numerically, so `08` is accepted for 8. On paper, accept either pictured addend order. | Write an equation with the correct total but addends that do not match the picture. |
| `storyadd1` | **Apply:** find the combined quantity after a group is added. | Numeric rule above; the value must equal the starting group plus the added group. The response does not have to show working. | Report only the newly added group. |
| `otherway1` | **Represent:** construct a different two-part composition of the same whole. | Online: two fields must each contain a positive one-digit whole number; their sum must equal the shown total, and their unordered pair must differ from the pictured pair. Either order of a new pair is accepted. On paper, a readable labelled drawing or horizontal equation meeting the same conditions earns one mark; see the [full rubric](p1-exit-ticket.md#marking-the-two-open-response-items). | Reverse the pictured pair and call it a different composition. |
| `triangle1` | **Identify:** recognise a triangle by its three straight sides despite rotation. | One mark for choosing exactly the correct letter among A, B and C; blank selection must be completed. | Choose the tilted quadrilateral because its orientation resembles a triangle, or choose the circle without checking straight sides. |

**Response-policy decision.** New `v=3` P1 numeric items use the whole-number response specified in the [exit-ticket brief](p1-exit-ticket.md#ordered-item-briefs). `v=2` keeps its published scoring rule so an old pupil link still marks as it did when shared. Both versions retain the same question IDs, values, paper and worked key; the version selects the online response policy. The purpose labels and misconception hypotheses should be revisited with item-level classroom evidence.

## From plan to release

1. Build the nine fixed examples first. Store each quiz as an ordered set of versioned questions containing language, values, diagrams, answer rules, marks and worked steps. Reopening a quiz must reproduce it exactly.
2. Generate a separate downloadable A4 question paper and answer key from the same record. Check Chinese glyphs, grayscale diagrams, space for working and page breaks. Give P1 pupils large targets online. Offer keyboard input and labelled controls for selection and numeric answers.
3. Add a teacher preview with single-item replacement, then shareable links. Practise mode gives feedback after each item. An assigned quiz shows solutions after submission. The first release assumes account-free self-marking. Explanations and open-ended investigations require a rubric or teacher review.
4. Turn reviewed examples into generators. Test boundary values, equivalent answers, unique choices, unit conventions and agreement between each diagram and solution. Only enable a skill in the builder once it has a reviewed bilingual template and passes print and mobile checks.
