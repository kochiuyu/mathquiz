# Full curriculum development plan

This plan tracks all 85 EDB learning units. A **task live** status means one or more questions are available; it does not claim that all objectives in that unit are covered. **No task** means the unit is still absent from the teacher builder. Source-check each numbered objective and its remarks before release. Manual classroom, translation, physical printer and screen-reader checks remain deferred at the user's request.

## Release standard

For each unit: (1) review every objective, boundaries and exclusions in the EDB supplement and explanatory notes; (2) map each objective to a distinct identify, represent, calculate, apply or explain task when screen assessment is appropriate; (3) use a printable rubric for construction, inquiry and physical measurement; (4) provide English and Traditional Chinese prompts, answers, worked feedback and three-question practice; (5) verify every finite variant, marking boundaries, builder, pupil link, paper, key, PDF and old links locally and after deployment. Mark a unit complete only after every objective has a live task or an explicit documented reason it requires teacher-led assessment.

## Immediate sequence

1. Finish the open 1N3 objectives, then complete the remaining P1 objectives and units; a released family addresses only its mapped objective.
2. Continue P1–P6 unit by unit, preserving permanent question IDs and existing shared links.
3. Add teacher-marked printable activities for units that require drawing, hands-on measurement, investigation or open explanation.
4. After each release, update this inventory, the curriculum map, live family ledger, bilingual coverage page and README checkpoint.

**Next:** audit the remaining oral and listening aspects of 1N3; then develop 1N4 and other P1 units. Eight live families cover fixed written and pictured parts of 1N3, but the unit is still partial.
