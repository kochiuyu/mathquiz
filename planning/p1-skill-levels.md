# P1: three levels for every selectable skill

## Corrected scope

The requested rollout is **each of the 38 selectable P1 skills**, not one collection for each of the twelve curriculum units. The earlier [unit collections](p1-all-levels.md) remain supplementary resources. They do not satisfy this per-skill requirement by themselves.

[Open the skill-level page](https://kochiuyu.github.io/mathquiz/p1-skill-levels.html). Every P1 skill card in the main resource library links directly to its corresponding skill. The page groups its selector by curriculum unit and offers Easy / Normal / Difficult, four stable three-question sets, or all twelve questions at once.

The bank contains **38 × 3 × 12 = 1,368 bilingual questions**. Each skill has 36 questions, with twelve in each level. These are separate from both the 432 unit-collection tasks and the core mixed-quiz catalogue. There are nine units with these 38 selectable skills. Time, position and inquiry resources in the other three P1 units still have their earlier unit collections and teacher activities; they are not invented extra members of the 38.

## Meaning of the levels

- **Easy / 容易:** the target skill with a usable cue, reference model, visible grouping, aligned starting points or a supplied intermediate step.
- **Normal / 一般:** apply that same skill with less scaffolding, such as independent counting, an unlabelled classification, or a nonzero measurement start.
- **Difficult / 較難:** recover missing information, correct a plausible error, compare methods or choose an explanation. Stay inside the skill's P1 number and concept limits.

These are **provisional teaching levels**. They describe task demands, not fixed ability groups, measured item difficulty or mastery. An adult may read aloud. More reading alone is not the intended challenge; a teacher can check the pupil's reasoning orally. Existing core questions are not retrospectively labelled Easy, and a difficult score is not directly comparable to an easy score because some questions have more answer parts.

## Curriculum boundaries and source

Use the [EDB key-stage-one explanatory notes](https://www.edb.gov.hk/attachment/en/curriculum-development/kla/ma/curr/EN_KS1_e.pdf), alongside the existing source-checked P1 briefs in this directory. This release deepens the named skills; it does not declare that each whole unit has been exhaustively assessed.

- 1N1 counting remains within 20. Number-bond parts are positive one-digit numbers, with totals no greater than 18. Alternative-pair tasks explicitly exclude a mere swap of the pictured pair.
- The core `add1` range stays within ten. Pictured and short-story addition uses positive one-digit parts and totals no greater than 18. Horizontal pictured sentences do not introduce column forms into 1N2.
- 1N3 stays within 100. Group counting uses 2, 5 or 10 without multiplication notation. The value 100 may be represented as ten tens; no formal hundreds-place assessment is added. Number words are printed, so listening is not assessed. Choosing the nearest estimate does not establish that the pupil actually estimated rather than counted.
- 1N4 keeps two-digit addition totals below 100, no-borrow subtraction, three-addend addition without brackets and two-number stories. Explanations use choices; a formal written explanation is not required.
- Money uses labelled Hong Kong values, prices/totals at most HK$10 and no decimal-calculation requirement. It does not test real-coin recognition, making change or coin exchange.
- 1M1 retains direct comparison, straight distance and equal improvised units. 1M3 uses whole-centimetre ruler markings. All ruler drawings are schematic; resizing or printing cannot turn them into physical measuring instruments.
- 1S1 retains the five broad solid families, without a new faces/edges/vertices or nets requirement. Triangle tasks use closure and three straight sides, not formal angle terminology. Real/tactile models remain appropriate alternatives.

## Interface, answers and compatibility

1. Each resource-card link selects that exact skill and current language. Unit links select an available skill in the unit; time, position and inquiry retain their earlier unit pages.
2. Stable IDs are `p1s-<skill>-<level>-<1..12>`. Sets 1–4 partition a level's twelve items; they do not randomly replace questions. Quiz, paper and worked key retain IDs and order.
3. Every response part has a label. Pictured-addition answers form a horizontal sentence; column-skill answer digits physically occupy the tens/ones cells. Long selected explanations are repeated below their select field so they can wrap on narrow screens.
4. All parts must be attempted before marking. Results include per-question feedback and partial credit. Marked controls lock; repeat submission cannot add credit. Retry clears that attempt. Language changes retain answers and marked state for the same set.
5. `otherway1` accepts every valid alternative positive one-digit pair, in either order, rather than accepting only the example in the key. The two pair entries are marked jointly; an explanation is a separate part. Blank, malformed and out-of-range pairs are rejected.
6. Browser Print / Save as PDF provides a pupil sheet and separate worked key. Direct PDF download and mixed-builder composition of the new questions are not part of this release. The ordinary builder and its permanent IDs/marking stay available.
7. The three-question default limits initial work; All 12 supports longer practice or printing. Starting another set clears answers, as stated beside the controls. Difficulty labels and session scores do not claim curriculum mastery.

## Verification and evaluation

The static gate compares the exact 38 IDs, bilingual labels and unit assignments with the current core catalogue. It independently checks every numerical/value-choice answer, all 114 twelve-question groups, unique question payloads, deterministic set partitions, scope limits and diagram rendering. It also exhaustively tries 2,904 alternative-pair responses, including zero, out-of-range parts, wrong totals and swaps of the shown pair.

The browser runner exercises every skill × level × language with all twelve questions in quiz, paper and key: blank/wrong/correct marking, repeat prevention, retry, feedback and content parity. Additional checks cover partial credit, language transfer, valid alternative answers, column alignment, all 38 resource links, invalid routes, narrow layouts and 200% text sizing. Existing core and UI static gates protect the original payloads and links. A small legacy integration check is included; this is not a rerun of the full historical browser suite.

Local verification passed **251/251 browser checks**, plus six fresh bilingual quiz/paper/key checks of the guided solid-reference trays. The final static bank gate, core gate (175 permanent families / 2,661 unchanged variants), UI gate and previous unit-collection gate passed. An initial narrow-screen selector overflow was fixed with shrinkable grid controls before the successful browser run. The final corrected runtime is [1356b32](https://github.com/kochiuyu/mathquiz/commit/1356b325ebc134946d50c6be0dbf37ec502c37bc), following initial release 4ef05df. Pages run 44221326378 succeeded. Its final local run passed 251/251; the public full run passed 250/251 with one answer-key page-load timeout. An isolated quiz/paper/key rerun of the timed-out case passed 1/1, verifying all 251 distinct checks. The timeout is retained in the [machine-readable evidence](p1-skill-release-evidence.json). Public and local question-payload hashes match. A final rendered-question comparison found and corrected the repeated twelfth measurement drawing in four skills before these final runs; the static gate now rejects duplicates of the actual bilingual rendered tasks, not only duplicate metadata. A Chinese mobile resource-card click also reached the exact intended skill without page overflow. Human pupil trials, independent Traditional Chinese review, physical output and full assistive-technology testing remain deferred. Automated checks do not establish usability or accessibility conformance.

For later calibration, sample pupils on one skill at a time, record assistance and misconceptions as well as answers, and compare performance across levels without treating speed alone as difficulty. Revise the cue or reasoning demand if the proposed levels do not separate as intended. Do not relabel a child from one score. Keep those review findings separate from implementation completion.
