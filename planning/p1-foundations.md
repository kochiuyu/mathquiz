# Early P1 foundations: teaching before extension

20 November 2026. This implements the guided-teaching concerns in the P1 coverage review before any guided P2 expansion. [Start after counting and tens](../learn.html?path=numberstart).

## Recommended sequence

Existing `count` → `tens` → new `countsteps` → `order20` → `pair20` → a small check → `split18` → `swapjoin` → `zeromoves` → a small check → existing `add` → existing subtraction and later number work.

The existing first-topic overview displays the bridge before addition. When a pupil finishes its first two lessons and has not already started addition, the next practice action points to the unfinished foundation lesson. That destination is saved as their cursor. Finishing the new parts topic returns to addition once both foundation topics have been practised. Existing addition work resumes as before; nothing is deleted or forced to restart. All lessons remain directly accessible; this is a recommended route, not a lock.

## Six original bilingual lessons

| Lesson | Teaching and scope | Practical evidence |
|---|---|---|
| Count on and back | By one, within20, including crossing10 and counting back from20. | Take a specified quantity, speak sequences, read and write dictated numerals. |
| Which place? How many? | Cardinal total versus ordinal position from a named end, within20. | Point to real objects and compare small collections. |
| Make pairs | Odd/even by actual pairs, including19/20; no two-digit digit rule. | Pair objects and explain any unpaired counter. |
| Make parts before adding | Two single-digit parts, totals2–18; move/say before symbols. | Compose/split12, boundary examples2/18, name operation signs. |
| Swap the parts | Compare swapped addends using the same counters; contrast subtraction, within10. | Repeat joining in both orders; explain why insufficient objects cannot be removed. No negative-number calculation. |
| What does zero change? | Starting empty, adding none, taking none and taking all. | Demonstrate0+n, n+0, n−0 and n−n with two different starting quantities. |

Each lesson has three teaching steps, two guided questions and three questions at each practice level. Easy uses representations, Normal reduces selected support while keeping necessary diagrams, and Difficult asks pupils to correct a claim, predict pairing after adding one, or distinguish subtraction from swapping addends. Levels remain provisional. The additions give54 levelled practice items; totals become15 pathways,45 lessons,405 levelled items and15 investigations. These counts are not curriculum objectives or mastery totals.

Early positions/pairing are now available before100. The earlier `position` and `parity` lessons remain later consolidation/extensions, preserving saved work. Repetition of a concept is intentional; old questions are not silently redefined.
