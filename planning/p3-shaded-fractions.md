# P3 shaded fractions of one whole · item brief

Status: **draft, not live**. This brief defines the first bilingual P3 fractions family. Manual pupil and hands-on screen-reader checks remain deferred at the user's request.

## Curriculum match

- **Year and unit:** Primary 3, 3N5 “Fractions (I)”. [EDB's 2017 primary supplement, objective 1](https://www.edb.gov.hk/attachment/en/curriculum-development/kla/ma/curr/pmc2017_e.pdf#page=48) includes fractions as parts of one whole object and parts of a set. This family assesses the one-object case only. A pupil counts the shaded parts and the equal parts in a rectangular whole, then writes those counts as a fraction.
- The [2018 Key Stage 1 explanatory notes, 3N5](https://www.edb.gov.hk/attachment/en/curriculum-development/kla/ma/curr/EN_KS1_e.pdf#page=54) emphasise equal parts and reading/writing the numerator, denominator and fraction line. Fractions are at most 1; the notes include 0 and 1 as boundary values. Equivalent fractions, comparison, and same-denominator addition/subtraction are separate objectives. This family's worked feedback may note equivalence but does not separately test those objectives.
- **Prerequisites:** Counting up to eight and distinguishing a part from the whole. The curriculum match is this project's interpretation of EDB sources, not EDB approval or evidence of pupil mastery.

## Proposed item

The picture shows one rectangular bar divided into equal parts. Some are shaded. Ask for the number shaded over the total number of equal parts **as drawn**. This instruction makes the requested response unambiguous when a mathematically equivalent fraction uses different counts.

| Element | English | 繁體中文 |
|---|---|---|
| Pupil prompt | What fraction of this whole bar is shaded? Put the number of shaded parts above the line and the number of equal parts shown below it. | 這條完整長條有幾分之幾塗了顏色？把塗色部分的數目寫在分數線上方，把圖中等分的總數寫在下方。 |
| First example | One of four equal parts is shaded. Answer `1/4`. | 四個等分中有一個塗色。答案是 `1/4`。 |
| Boundary examples | No parts shaded in five equal parts: `0/5`. All six shaded: `6/6 = 1`. | 五個等分都沒有塗色：`0/5`。六個都塗色：`6/6 = 1`。 |
| First wrong-answer hint | Count all the equal parts for the number below the line. Then count only the shaded parts for the number above it. | 先數所有等分，把總數寫在分數線下方；再數塗色的等分，把數目寫在上方。 |

**Diagram contract:** Draw one outlined whole bar partitioned into equal-width, bordered cells, with shaded cells dark enough in grayscale. Vary the shaded cells' positions so the pupil cannot rely on “the first few cells”. Paper, key and practice derive from the same stored record. The alt text describes the one whole, number of equal cells and an ordered sequence of “shaded” and “not shaded” cells, without announcing the fraction. Keep the diagram and stacked numerator/denominator response together on A4; keyboard order is numerator then denominator.

**Variant plan:** Freeze twelve permanent IDs before release. Use denominators 2, 3, 4, 5, 6 and 8, with numerator from 0 to denominator. Include `1/4`, `2/3`, `2/4`, `0/5` and `6/6`, and more than one shading arrangement. Each record stores part count, shaded count, shaded positions, bilingual prompt, worked step and diagram data. Older IDs and shared links must remain unchanged.

## Marking, practice and release checks

- **Online:** Use separately labelled numerator and denominator fields; both must be present. Award one mark only when they exactly match the shaded-cell count and total-cell count **in this picture**. Accept trimmed whole-number numerals after full-width-digit normalisation. Require an explicit `0` for an unshaded bar. Reject decimals, calculations, a reversed pair and an equivalent fraction with different counts, because the prompt asks for the counts shown. A worked explanation should acknowledge that an equivalent form can represent the same amount while explaining why it does not answer this counting instruction. Apply this rule only to the new family.
- **Paper and key:** Print a stacked fraction blank. The key identifies the count of all equal parts and shaded parts, then the displayed fraction. For `6/6`, note that the whole is shaded. Check both zero and full examples, a reducible fraction, English and Chinese A4 output.
- **Practice:** Begin with `1/4`, show the counting hint after a wrong first attempt, allow one retry, and then show the worked count. Follow with distinct diagrams, including `2/3` and `2/4`. Track first-try success separately.
- **Automated release checks:** Enumerate all twelve records and independently verify the cell count, shading count, bounds, bilingual prompts, field labels and key. Test accepted and rejected answer forms, blank prompting, hint/retry and distinct follow-ups, phone width, A4/PDF output and older links. Manual pupil and hands-on screen-reader checks remain deferred and must not be marked complete.

**Scope limit:** The family assesses reading a fraction from one pre-partitioned rectangular whole. It does not test fractions of a set, deciding whether unequal parts are valid, equivalence as a separate skill, comparing fractions, calculating with fractions or the full 3N5 unit.
