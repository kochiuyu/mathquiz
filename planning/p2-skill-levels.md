# P2: Easy, Normal and Difficult for every selectable skill

## Scope and teaching purpose

The rollout covers **all 41 currently selectable P2 skills**, across fourteen units. Each has twelve questions at each of three levels: **1,476 bilingual levelled tasks**. The inquiry unit 2F1 has teacher-observed resources rather than a selectable skill; it is not counted as a forty-second skill.

[Open P2 skill levels](https://kochiuyu.github.io/mathquiz/p2-skill-levels.html). Every P2 card in the resource library links to its exact skill. The selector groups skills by unit and offers four fixed sets of three questions or all twelve.

This bank deliberately uses **492 representative existing contexts, each presented with three teaching demands**. It is not 1,476 unrelated numerical contexts. A source family may have more than twelve variants; twelve representative contexts are frozen here, including zero/one and varied table rows where appropriate. Existing core questions are not all relabelled Easy.

- **Easy / 容易 — guided:** an explicit skill-specific method cue, alongside any existing diagram. For example, a time cue splits counting at the next hour, while a division cue distinguishes full groups from leftovers.
- **Normal / 一般 — apply:** the existing mathematical task without the added cue, answered independently.
- **Difficult / 較難 — reason:** the core answer plus required checking or explanation. Some skills add a numerical intermediate or further step; others ask pupils to select a mathematical reason or reject a misconception. Geometry can require separately checking the conditions behind a classification.

These are provisional teaching levels, not measured ability bands. Difficult does not mean beyond-P2 arithmetic. The same context can be used to compare the amount of assistance or reasoning needed, but repeated exposure may improve a score through familiarity. For later pupil calibration, use different sets across levels and record help given, reasoning and misconceptions, not speed alone. An adult may read the question and choices aloud. Selected explanations do not measure unaided written explanation.

## Curriculum boundaries

The [EDB key-stage-one explanatory notes](https://www.edb.gov.hk/attachment/en/curriculum-development/kla/ma/curr/EN_KS1_e.pdf) and the existing P2 unit briefs govern scope. This release adds teaching demands to existing skills and does not claim full digital assessment of every objective.

- 2N1 uses numbers through 999; 2N4 through 9999. Extra sequence steps stay in range. Group counting uses running totals rather than a new multi-digit multiplication algorithm.
- 2N2 addition uses at most three addends and totals through 999. Subtraction operands remain at most two digits. Chains are nonnegative and evaluated in the stated order. 2N5 retains three-digit subtraction and three-operand addition/subtraction with bounded intermediates.
- Multiplication uses table factors 0–10. Division uses a nonzero divisor 1–10, quotient at most 10 and dividend at most 100. Remainders are smaller than divisors. No fractional quotient or long-division algorithm is introduced.
- Metre tasks convert to centimetres, not decimal lengths. Time tasks use whole-minute intervals of at most 60 minutes and do not introduce inverse-start-time, multi-hour or 24-hour-conversion demands.
- Money stays within HK$1000. Dollar/cent parts are handled separately, not as a new decimal-arithmetic topic. Note exchange stays inside either {$10, $20, $50, $100} or {$100, $500, $1000}; a task cannot introduce a denomination from the other group. Labelled money does not assess authentic note/coin recognition.
- Solid tasks use the stated prism/pyramid family and base polygons with 3–6 sides. An outline is explicitly the base, not a complete solid drawing. Angle tasks use right-angle comparison without pupil-facing degree measures. Direction tasks use four cardinal directions and the indicated north arrow. Quadrilateral criteria stay separate from a square-as-rectangle taxonomy question.
- Pictograms retain one symbol per pupil. No scaled-symbol interpretation is introduced. Physical measuring, construction, authentic-object recognition and inquiry remain teacher-observed where required.

## Delivery and answer contracts

The new bank is separate from the mixed-quiz builder and direct PDF exporter. Existing permanent IDs, frozen payloads and original marking contracts remain intact. Browser **Print / Save as PDF** provides a pupil sheet and a separate worked key. Core family totals and curriculum-completion flags do not change because of this bank.

The frozen contexts in `p2-skill-seeds.js` record their core IDs and source revision. The builder utility selects them from the audited source and captures existing bilingual figures. Regenerating seeds is an intentional content change, not an automatic runtime operation. IDs `p2s-<skill>-<level>-<1..12>` identify tasks. Sets 1–4 partition the twelve; quiz, paper and key retain identical ordering.

Each required response part earns one mark in this bank. Partial credit is therefore explicit; it is not necessarily the original core question's mark allocation. In `groups2a`, both valid factor orders are accepted; the two factor fields earn their marks together, while product and explanation are separate. For `share2a`, share and remainder receive separate credit here; the original core all-or-nothing rule remains unchanged. Numeric inputs accept nonnegative integer numerals, full-width equivalents, optional leading plus and a zero decimal suffix, not arbitrary expressions. Choice answers use the displayed option.

Blank answers prevent submission. Marked controls lock; repeat submissions cannot accumulate marks. Retry clears the attempt. English/Traditional Chinese switching retains draft values or the marked result for the same set. Changing the selected set starts a new attempt. A selected long explanation is repeated below its control so it can wrap on a narrow screen. Scores describe this attempt, not mastery.

## Verification and subsequent evaluation

The static gate checks all 41 IDs against the current core catalogue, every frozen context against its source, all 1,476 answer/field contracts and all 123 twelve-question groups. Arithmetic, division, money, time, place values and geometry are checked from their mathematical metadata. It checks range restrictions, alternative factor order, set partitions, distinct displayed tasks within each level and JavaScript syntax. Existing core/P1/UI/P2 gates protect compatibility.

The dedicated browser runner covers every skill × level × language with all twelve questions in quiz, pupil paper and key. It checks blank/wrong/correct answers, partial credit, retry/locking, stable IDs, all 41 exact library links, all 38 preserved P1 links, language retention, malformed routes, narrow layouts and 200% text sizing. A page-load timeout can be retried once and is explicitly recorded; failed assertions are not silently retried. The existing UI runner is also used for shared navigation compatibility. These are dedicated and integration checks; the full historical curriculum browser suite is not rerun for this release.
