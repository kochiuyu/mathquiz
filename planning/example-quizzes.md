# Example quiz collection

The collection at [examples.html](../examples.html) contains 21 quizzes: 18 new themed selections, three for every grade P1–P6, plus the three original mini quizzes. Each new set contains six existing questions, with no item repeated across the 18 sets (108 distinct permanent IDs). These are curated selections of released questions, not new question families or calibrated difficulty levels.

The catalogue provides a labelled year filter, shareable year/language URLs, question counts, topic descriptions, pupil links, editable selections, printable papers and worked keys. The original mini quizzes keep their existing identities; the P6 route uses version 4 with its corrected percentage unit label. Original P1/P4 paper views now also have an explicit print button. Existing question payloads, marking and progression remain unchanged.

## Verification

The static gate checks 21 unique bilingual records, three six-question packs per grade, 108 unique live item IDs, exact item order and 162 mode/language URLs. The existing core and UI static gates check all frozen question payloads and shared UI contracts.

The 54-case browser runner covers both languages, all 21 quizzes, canonical-answer marking, identical paper/key payloads, worked explanations and all 18 editable selections. It also checks homepage discovery, year filters, language links, 320/768/1440px layouts, 44px controls and enlarged text. English desktop and Traditional Chinese mobile catalogue screenshots were inspected.

The first local run passed 48/54. Four failures exposed the original P1/P4 paper views' absent print button, now added. Two were a test expectation that counted the original P6 two-field speed question as one mark; the runner now uses the documented per-field default. Runtime marking did not change. Final local/live results are recorded in the README and release evidence.

Physical printing, independently reviewed translations, classroom difficulty calibration and full screen-reader testing remain deferred. The full historical curriculum browser suite and PDF export suite were not rerun for this catalogue change.
