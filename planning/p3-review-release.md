# P3 application review release

23 November 2026 · [Open the review](../p3-review.html) · [Evidence](p3-review-evidence.json) · [Freshness audit](p3-review-novelty.json) · [Coverage contract](p3-coverage-review.md).

## What changed

Sixteen bilingual application tasks in eight freely chosen pairs, nine practical stations and one continuing inquiry evidence record. Learners choose a session without operation headings. There is no timer, pass mark, readiness certificate or P4 lock. Amount matches do not assess reasoning; three explanation tasks are human-reviewed. No bank or guided score is imported.

Original estimates precede exact answers in M1/L2. F2 keeps an oral account before fraction notation. Fraction amount inputs accept equivalent positive-denominator fractions without requiring simplest form; the separate older picture-count contracts remain unchanged. Date context uses 6 May 2029 00:00, and the time problem asks for an afternoon start in h:mm. All task feedback and lesson links appear only after a nonblank first response; one supported retry is retained separately. Whitespace-only and empty responses are refused.

Each practical station requires an original plan/estimate record before an observed status. Original entries and inquiry question/prediction/plan cannot be rewritten without explicit review reset. Later observations and inquiry evidence are the latest continuing record, not a full history; retain additional dated estimates, drawings and trials on paper. Nine stations cover multiple activities across visits, not nine timed tests. An independent status requires actual date, task and explicit help or none, and is a human observation—not inferred from a correct screen answer or blank help.

Inquiry retains actual trials, a failed/disagreeing case, explanation, changed example, the date and who decided/manipulated/recorded/prompted. Existing dated originals may be transcribed with their source; a prediction must not be invented after seeing results. All 14 existing topic investigations remain available.

All P3 maps link to this review with learner/language/test context. The guided sample-check wording now says examples may revisit familiar tasks, in both languages; existing question IDs and first attempts are untouched. The shared script URL changed so browsers can fetch that clarification.

## Freshness and remaining parallels

The audit compares the new bilingual prompts against 1,014 guided/example/practice/check items, 1,800 generated bank questions and 14 P3 activity files. It finds no exact prompt after introductory-label removal and no matching ordered numeric array in the final tasks. Source hashes and all per-task candidates are retained. An initial draft reused the division pair 173/8 and fraction equivalence 3/4=6/8; those were replaced. The multiplication pair 137/6 also appeared in a division item and was replaced conservatively.

The new response contracts require learner-chosen calculations and explanations, unlike fixed roles/options in much earlier work. The fraction strips are equal-width wholes partitioned 6 and 12; the removal strip has ten equal parts with seven shaded and two removed; the new chart has paper/clay/beads frequencies 18/10/14 on scale 2. These rendered inputs were reviewed alongside their text alternatives. The chart is clearly supplied example data, not a claim of pupil collection.

This does not prove wholly unseen work. Place-value repair, successive division, same-whole equivalence, a nonzero ruler start, balance zeroing, inclusive names and midnight all intentionally revisit taught ideas. Small-number combinations recur in activity pages; files merely containing all tuple numerals are retained as candidates, not declared duplicates. The audit does not canonicalise every numeric object or raw SVG, paraphrase or external exposure. Adults should ask the pupil about prior familiarity and record any help. Repeated concepts are useful but do not certify independent transfer.

## Storage and compatibility

The new per-learner keys are `mathquiz-p3-review-v1-0/1/2`; isolated tests use `mathquiz-p3-review-test-v1-0/1/2`. The three profiles are pupils, not difficulty levels. Only submitted records are saved in this browser. First responses, retries, immutable originals, observations and inquiry are separate fields. No migration from previous marks. Reset requires the checkbox and affects only this learner’s review.

Writes compare the exact last-read record and refuse stale-tab edits, retaining drafts. Invalid JSON, future versions, malformed nested records and oversized input are protected until explicit reset. Storage blocked from startup or a quota failure keeps volatile work with a visible copy-your-work warning. Text fields are bounded; a full record refuses the extra write while retaining prior work. Inquiry/observations validate real dates, and HTML-like pupil text is displayed as text. This is browser-local storage, not cross-device sync or an assessment database.
