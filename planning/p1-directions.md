# P1 directions and positions (I): first activity and source audit

**Status:** bilingual teacher-led resource authored; independent, browser, print and publication verification pending. No complete-unit claim.

## Source scope

Checked 16 November 2026: [EDB 2017 supplement, printed p.19 / PDF p.22](https://www.edb.gov.hk/attachment/en/curriculum-development/kla/ma/curr/pmc2017_e.pdf#page=22) and [KS1 explanatory notes, printed p.17 / PDF p.23](https://www.edb.gov.hk/attachment/en/curriculum-development/kla/ma/curr/EN_KS1_e.pdf#page=23).

1S3 has one numbered objective: describe relative positions using seven terms from the pupil-observer’s viewpoint. The notes require both hands-on surroundings and simple pictures. Picture left/right is the pupil’s own view; no reversal into a facing character’s viewpoint. Over/under/front/behind use object-to-object descriptions. Complicated relational puzzles are unnecessary. Compass directions and turning instructions are not this unit’s target.

## Resource routes

[English pupil sheets](../activities/p1-directions.html?lang=en) · [Chinese pupil sheets](../activities/p1-directions.html?lang=zh) · [English key](../activities/p1-directions.html?lang=en&key=1) · [Chinese key](../activities/p1-directions.html?lang=zh&key=1)

Two pupil sections and a hidden teacher section per language. Static SVGs supply simple pictures, not merely written scene descriptions. Labels identify objects without naming the requested relation. Adult handling and tactile adaptations are available with the adapted assessment mode recorded. No drawing or movement requirement should obscure a child’s positional understanding.

## Objective 1 evidence map

| Required terms | Picture task and expected answer | Real-object task and observable evidence |
|---|---|---|
| Left / right | Task 1: A on left, C on right, from page reader’s view | Task 4a describes blocks from a marked viewing spot; task 5 separately asks pupil to place A on each side then describe. |
| Between | Task 1: B between A and C, either neighbour order | Task 4d describes A–B–C; task 5 places B between two fixed blocks and names both neighbours. |
| Over / under | Task 2: D over table, E under table | Task 4b describes ball above/below low table; task 5 makes safe placements or directs adult. |
| In front of / behind | Task 3: G ball in front of F box; F behind G | Task 4c puts ball nearer pupil and box farther on same viewing line; task 5 reverses their relation through separate requests and descriptions. |

All seven terms have picture and real-object description evidence. Task 5 is additional receptive/placement practice; it does not replace the expressive descriptions required by the objective. Rubric records each term and mode separately with independent/prompted/not-yet/not-observed categories, without an invented pass score.

## Geometry and teaching checks

- Left/right picture is a single horizontal row, with no facing person or ambiguous intrinsic orientation.
- Over/under scene shows a ball separated from and above a tabletop; a block is visibly below it between the legs.
- Front/behind scene uses occlusion: a ball covers part of a box front. Teacher key explicitly distinguishes depth from page height. The scene states a shared front view.
- Real-object observer stays at one marked position; teacher stands alongside. Both objects remain visible. No moving observer or left/right reversal puzzle is introduced.
- Between has two named reference objects; a response naming only one is not treated as full evidence.
- All practical placements are low and safe. No climbing or crawling under furniture; teacher performs inaccessible placements following pupil directions.
