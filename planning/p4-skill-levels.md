# P4: three teaching levels for all 51 selectable skills

[Open P4 skill levels](https://kochiuyu.github.io/mathquiz/p4-skill-levels.html).

## Scope and teaching design

All **51 selectable P4 skills** receive twelve Easy, twelve Normal and twelve Difficult tasks: **1,836 bilingual levelled tasks** across fourteen units. 4F1 inquiry remains teacher-observed. There are **612 contexts with three teaching demands**, not 1,836 unrelated numerical situations. Original questions are not all relabelled Easy.

Easy provides each context's explicit method cue. Normal preserves independent application. Difficult requires the original response plus a numerical check, sub-result or selected explanation that rejects a misconception. These labels are provisional teaching demands, not pupil-calibrated ability bands. Repeating the same context can improve performance through familiarity; use different sets when comparing levels.

## Source boundaries

Use the [EDB KS2 explanatory notes, P4 printed pages 1–23](https://www.edb.gov.hk/attachment/en/curriculum-development/kla/ma/curr/EN_KS2_e.pdf#page=7), and the existing source-reviewed P4 unit briefs. The source revision is `3a292f639fce3b5424627ea16833340b05a75e54`.

- Multiplication remains two/three digits by two digits; the additional partial product states its factors explicitly, including reversed original displays. Division uses two/three-digit dividends and two-digit divisors, bounded remainder checks and contextual interpretation. Divisibility tests remain 2, 3, 5 and 10; prime classification remains within 100.
- Factors/common factors and multiples/common multiples use positive values as requested. One is neither prime nor composite; zero is not inserted into a positive-multiple list. Zero dividend remains valid in divisibility contexts.
- Four-operation questions preserve the existing four/five-operand and non-nested-bracket limits. Unitary contexts retain a constant price. No new algebra, negative quantities or advanced ratio notation is introduced.
- Fractions preserve proper/improper/mixed/whole form distinctions, expansion/reduction and common-denominator addition/subtraction with at most three operands. A requested denominator is retained; lowest terms are required where the original task specifies them. No unlike-denominator calculation, fraction multiplication or division is added.
- Decimal meaning/place value includes the original four decimal places; decimal arithmetic stays within the existing two-place, two/three-operand addition/subtraction limits. Exact decimal scoring does not use floating-point tolerance. No decimal multiplication/division is added.
- Perimeter measures the outside boundary; shared internal seams are excluded. Area uses equal units, rectangle/square formulae and overlays without resizing. No triangle/circle area formula or square-unit conversion algorithm is added.
- Quadrilateral classes remain inclusive. Specified dissection and assembly tasks assess the shown cuts/placements, not every possible construction. Compass questions use eight directions and right-angle turns, not numerical bearings or map-scale calculations. Physical compass use remains teacher-observed.
- Chart tasks retain the source scales, supplied counts, rounding rules and explicit grid constraints. A selected explanation does not demonstrate original data collection or independent chart construction.

## Context sampling and preservation

The permanent core, previous P1–P3 banks, curriculum-completion flags and direct PDF exporter are unchanged. All 308 source files were verified against Git blob hashes before work began. Source families with more than twelve variants are sampled; the five 24-variant families retain both halves of their source sets. Original operand/representation coverage is checked separately from difficulty.

The compass-route family had eight contexts. Four additional contexts rigidly rotate the entire map, including the north arrow, facing arrow and roads, preserving the answer. Two visually duplicated area/perimeter contexts receive rigid shape rotations. These six adaptations are recorded in the frozen seeds and verified against the corresponding source transformation. Every skill/level has twelve distinct displayed tasks in each language. Rotation changes orientation, not length, area or compass relationships.

## Interface and answer contracts

Every P4 library card links to its exact skill. Stable IDs are `p4s-<skill>-<level>-<1..12>`. Four sets of three partition each level; all twelve can also be displayed. Quiz, pupil paper and worked key preserve IDs and order. Browser **Print / Save as PDF** is available. This bank is separate from the mixed builder and direct PDF download.

Each required response part earns one mark. Blank responses prevent submission; marked fields lock, repeated submissions add no credit, retry clears answers, and language switching retains drafts or marks. Long selected explanations wrap below the select. For the original multiple-factor task, each candidate receives an explicit Yes/No decision and one mark, so rejected candidates are assessed too. This differs from the core's all-or-nothing selection contract and is confined to this bank.

The existing exact fraction and decimal scorers are reused without modification. Fractions accept bounded whole, slash and mixed notation, with specified-form, denominator and lowest-term rules retained. One fraction earns one mark, with no numerator-only partial credit. Decimal values accept equivalent terminal zeros; digit/count fields retain integer syntax. Fraction fields use a text keyboard and decimal-value fields a decimal keyboard; all entries are bounded to 80 characters. Expressions, exponents and unit suffixes are rejected.

## Verification and limitations

The final deployed difficulty runner passed **329/329**, with zero failures and zero navigation-timeout retries. All **193 public UI cases are verified** across the recorded full runs and isolated reruns. The first UI run had an un-reproduced perimeter-layout assertion; the second passed perimeter but had a home-page load timeout. Both cases then passed their original assertions in isolated reruns. The local full difficulty run passed 329/329; four affected bilingual cases passed again after the factor-wording refinement, with all answers and other tasks unchanged. Local UI checks passed 193/193. All 29 static gates passed; 420 bilingual figures had no out-of-bounds text. All 1,836 deployed question records and eight runtime assets match the local build. See [release evidence](p4-skill-release-evidence.json) for hashes, original failures and rerun provenance. The dedicated bank gate checks exact coverage, source provenance and six transformations, 1,836 answer contracts, added numerical checks, form-specific alternatives, distinct tasks and stable sets. Existing independent P4 gates cover underlying arithmetic, fractions, decimals, geometry and charts; core and P1–P3 gates protect existing releases. Browser checks cover every skill × level × language through twelve-question quizzes, papers and keys, plus marking, language retention, previous-grade links and responsive layout. A navigation timeout has at most one recorded retry; assertions are not retried silently.

Pupil calibration, independent translation review, actual printing and full screen-reader assessment remain deferred. Automated checks are not a usability/accessibility conformance claim or evidence of mastery. Practical construction, measuring, compass use and inquiry remain teacher-observed; no curriculum-completion flag is promoted by this release.
