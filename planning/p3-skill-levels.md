# P3: three teaching levels for all 35 selectable skills

[Open P3 skill levels](https://kochiuyu.github.io/mathquiz/p3-skill-levels.html).

## Scope and design

All **35 current selectable P3 skills** receive twelve Easy, twelve Normal and twelve Difficult tasks: **1,260 bilingual levelled tasks**. There are thirteen units with selectable skills. The 3F1 inquiry activity remains teacher-observed and is not invented as an extra scored skill.

The bank uses **420 existing contexts at three teaching demands**, not 1,260 unrelated numerical contexts. Normal preserves the mathematical question; Easy adds its explicit method cue; Difficult requires extra checking, a numerical sub-result or a selected explanation. These are provisional teaching levels, not measured ability bands. Previous questions have not all been relabelled Easy. Familiarity from repeating a context can improve performance; later calibration should use different sets across levels and record assistance and misconceptions, not speed alone.

Most source families have twelve variants. Multiplication has twenty-four: the selection retains all twelve operand pairs and alternates the displayed factor order, rather than taking every second item and losing half the pairs. Frozen seeds record the original core IDs and source revision. Original permanent payloads and scoring remain intact.

## Source limits

Use the [EDB key-stage-one explanatory notes](https://www.edb.gov.hk/attachment/en/curriculum-development/kla/ma/curr/EN_KS1_e.pdf#page=49) and the existing source-checked P3 briefs in this directory. These are deeper tasks for current skills, not a claim that all objectives can be assessed digitally.

- Five-digit number work stays at or below 99999. The harder sequence task asks for a preceding term, not a sixth-digit term beyond the published upper boundary.
- Multiplication retains two/three-digit by one-digit and three-factor scope; division uses two/three-digit dividends and one-digit nonzero divisors, including remainders and contextual rounding. A numerical answer is not evidence that a pupil can lay out a column method independently.
- Mixed arithmetic uses bounded four-digit values, at most four operands, non-nested brackets and no new mixed-division requirement. Formal distributive rewriting is not required.
- Fractions stay at most one whole. Comparisons use like numerators or denominators, and diagram operations use at most three like-denominator fractions. No expansion/reduction algorithm, improper fractions or simplest-form requirement is added. Cross-products used in test code are engineering checks, not pupil tasks. `frac3a` specifically asks for the displayed part counts, so an equivalent reduced pair does not answer those two count fields.
- Length converts cm/mm to mm, not to decimal lengths or compulsory reverse compound units. Ruler drawings are schematic, not physical instruments. Capacity reading remains in mL; weight converts kg/g to g without decimal arithmetic.
- Start-time questions retain whole-minute durations up to 60 or whole-hour durations up to 12 hours, within the stated same-day context. 24-hour skills concern notation and day boundaries, not interval calculations in 24-hour notation.
- Geometry preserves inclusive parallelogram and triangle relationships, strict triangle inequality, side marks and right-angle information. No angle-sum theorem, Pythagoras, formal proof or degree calculation is required. Real drawing, construction and tool use remain teacher-observed.
- Bar charts retain their actual scale and orientation. A chart-reading score does not assess collecting data or constructing an original chart. Inquiry remains an existing teacher-observed activity.

## Interface and marking

Each P3 resource card selects the exact skill and language. IDs are `p3s-<skill>-<level>-<1..12>`. Four sets of three partition a level's twelve tasks; quiz, pupil paper and worked key preserve IDs and order. The three-question default avoids displaying a long worksheet immediately.

Each required response part earns one mark in this bank. Blank responses prevent marking; submitted fields lock; repeated submission cannot add credit; retry clears that attempt. A language switch retains drafts or marked results for the same set. A new set starts a new attempt. Long selected explanations are repeated as wrapping text below their control. Fractions have numerator and denominator fields above and below a visible fraction line. These two count fields receive partial credit here, independently of the original core's one-mark contract.

Numeric fields accept nonnegative integer numerals, full-width equivalents, optional leading plus and zero decimal suffixes. They do not evaluate arbitrary expressions. Fraction-choice questions use their displayed options. Scores describe a set, not mastery; selected explanations do not establish unaided written reasoning. An adult may read questions aloud.

The bank remains separate from the mixed builder and direct PDF exporter. Browser **Print / Save as PDF**, pupil papers and worked keys are provided. Earlier P1/P2 banks, core family counts, existing quiz links and curriculum-completion flags are preserved.

## Verification and calibration

The new static gate checks the exact skill list, labels and units; all 420 seeds against released source; all 1,260 response contracts; numerical additional checks; distinct displayed tasks in each language; stable sets; preserved multiplication categories; syntax and ranges. Existing independent P3 gates verify the source arithmetic, fractions, time, measures, geometry and charts. Core/P1/P2/UI gates protect previous releases.

The browser runner covers all 35 skills × 3 levels × 2 languages, with twelve questions in quiz/paper/key for each case. It checks blank/wrong/correct marking, retry and duplicate submission, print parity, all P3 library links, preserved P1/P2 links, partial fraction credit and vertical fraction placement, language retention, invalid routes, small screens and 200% text. A page-load timeout receives at most one recorded retry; assertion failures are not retried silently. The shared UI runner separately checks navigation compatibility. This is not a rerun of the full historical curriculum browser suite.

Release `90ba1f4` is published and verified. The deployed runner passed **231/231 difficulty checks and 193/193 shared UI checks**, with zero failures and zero navigation-timeout retries. All 1,260 deployed question payloads and seven runtime assets match the local build. All thirteen static gates passed. The local full run passed 230/231; its one test-harness error was corrected and that case passed 1/1. Four affected bilingual skill/level cases passed again after refining midnight/noon minute explanations, while all other tasks stayed unchanged. Thus all 231 distinct current cases are verified locally; local UI checks passed 193/193. Automated text-bound checks covered 264 rendered SVG figures with zero out-of-bounds labels. See [release evidence](p3-skill-release-evidence.json) for the original failure, reruns and exact hashes.

Human pupil calibration, independent translation, physical printing and full assistive-technology review remain deferred. Automated success is not a usability or accessibility-conformance claim.

For later calibration, sample pupils across several skills, vary set order, record prompting and misconceptions, and revise cues or reasoning demands that do not separate as intended. Keep practical observation and curriculum-completion evidence separate from difficulty labels.
