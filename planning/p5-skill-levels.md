# P5 levelled practice

This candidate covers all **53 selectable P5 skills** with **636 sampled contexts** and **1,908 labelled tasks** across Easy, Normal and Difficult. Some extra checks ask pupils to identify an explicitly supplied factor, equation-side value or unit count, rather than introduce a new calculation. These are teaching demands, not calibrated ability or mastery levels. Reusing a context at three demands does not create three independent numerical situations. P1–P4 retain 5,940 tasks byte-for-byte. All P5 resource-completion flags remain false pending verification.

Easy adds a relevant method cue; Normal retains independent application. Each Difficult task requires a context-specific calculation, verification or classification, plus a method/misconception choice. A correct generic statement alone cannot complete a Difficult task. All 696 contextual extra fields are independently checked, alongside bilingual rendered keys.

## Context selection

Each skill contributes 12 contexts. All eight direct equation-story forms appear before four solving/checking contexts. The three additional legacy circle contexts are rigid 15-degree rotations of existing drawings, resulting in orientations 15°, 105° and 195°; endpoint classifications are unchanged. They are new orientations, not new numerical situations. All figures are regenerated from the same reviewed production renderers used by core quizzes, including corrected polygon-language labels and visible cube faces.

## Assessment and integration

The displayed denominators determine the comparison-fraction common denominator. Story multiplication displays an explicitly ordered expression before asking about its first factor. Rounding checks use the requested scale. Exact fraction checks require reduced form through the unchanged shared grader; decimal checks retain exact value-mode grading. Legacy paired fraction responses retain paired correctness.

Purchase-equation grading is unchanged. New P5 expression and direct-equation fields use the scoped algebra parser per question, not per family. Direct modelling accepts reversed corresponding sides but rejects a solved-only equation; later numeric-solving contexts remain exact fraction fields. New algebra supports its stated lowercase x and ordinary operators; fullwidth digits are supported, but fullwidth operators and uppercase variables are not promised. Algebra fields have a text keyboard in fixed and Smart practice.

The directory, fixed-session navigation, resource filters and Smart adapter include P5. P6 has no level bank. Original direct core routes remain available. Smart keeps three consecutive complete, first-try, unassisted answers per level and preserves prior reset, replay, storage and review semantics. Its engine is unchanged.

This is a private candidate, not a claim of deployment or resource closure. Full browser verification is separate from static/oracle evidence. Physical printing, independent translation, screen-reader validation and classroom calibration remain unperformed. No unit completion follows merely from a pupil completing a session.

## Practice-feedback correction

Six newly developed numeric shape/data families now provide bilingual method hints for incorrect-answer recovery. Exactly 72 core payloads gain only this field; all other 3,279 payloads remain identical. The private pre-integration baseline has 3,009 preserved variants; the public baseline has 2,853 preserved variants. These are distinct baselines, not interchangeable deployment claims. All 1,908 level-task prompts, answers, figures and teaching demands remain identical to the independently reviewed bank. The six skills retain their earlier level-guide cues; regenerated seeds merely embed the new core hint metadata. Wrong-answer recovery has focused production-handler coverage and newly added browser cases awaiting the final rerun.
